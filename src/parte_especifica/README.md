# Parte Específica — TMDB 5000

| Arquivo | Conteúdo |
|---|---|
| `eda.ipynb` | EDA completa (estrutural, faltantes, outliers, tratamento, distribucional, relacional) e os gráficos de cada pessoa com as notas |
| `dados.py` | `carregar_filmes()`, `tratar(df)` (escolhas em `DECISOES`) e `explodir()` para análises por gênero |
| `estilo.py` | identidade visual: paleta, fontes, formato brasileiro, `aplicar_estilo(fig)` |
| `graficos.py` | os gráficos do notebook em plotly, com o estilo do projeto (catálogo `GRAFICOS`) |
| `notas.py` | notas analíticas de cada gráfico (mesmo texto do notebook) |
| `dashboard.py` | app Streamlit: `streamlit run src/parte_especifica/dashboard.py` (da raiz) |
| `vitrine_estilo.py` | vitrine do estilo com dados fictícios |

Visão geral, decisões e como rodar estão no [README da raiz](../../README.md).
